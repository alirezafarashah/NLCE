# 🏘️ Neighborhood Concept Creation

This folder includes code to create the large file that will be queried at unlearning time to find neighborhood concepts.

⚠️ **It is strongly recommended to download the pre-generated version**, as generating it from scratch requires significant time and compute resources.

The pre-generated data file, the data sources used in the notebook and the pre-trained SVR model could not be included due to space constraints and external linking guidelines.
