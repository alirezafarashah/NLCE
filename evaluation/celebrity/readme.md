# GIPHY Celebrity Detector 

For the evaluation of the celebrity eraser, we utilized the GIPHY Celebrity Detector. Please refer to their [official installation instructions](https://github.com/Giphy/celeb-detection-oss/tree/master/examples) for setup, or alternatively, follow the easier installation guide provided by [MACE](https://github.com/Shilin-LU/MACE/tree/main/metrics).
